# Slack 관리자 알림 미리보기

서버와 AI API 없이 사용할 수 있다. 대시보드의 집계로 Slack에 넣을 메시지를 만들고 터미널에 표시한다. 이 명령은 미리보기 전용이다. 실제 전송 명령의 설정은 [Slack 전송 안내](slack-delivery.ko.md)를 본다. 예약 실행은 아직 연결하지 않았다.

## 사용법

갱신 명령의 마지막에 `--slack-preview`를 붙이면 새 갱신본을 만들고 그 아래에 미리보기를 출력한다. 보관된 갱신본에 대해 미리보기만 다시 보려면 프로젝트 루트에서 실행한다.

```powershell
python -m streamlit_app.slack_preview --data-dir "work/operations/refresh-one-command-20261128"
```

중복 방지를 시험하려면 동일한 명령을 두 번 실행한다.

```powershell
python -m streamlit_app.slack_preview --data-dir "work/operations/refresh-one-command-20261128" --simulation-db "work/operations/slack-preview-test.db"
```

시험 기록은 지정한 별도 파일에 남는다. Slack 발송 기록과 연결하지 않는다. 저장소 규칙과 다른 파일로 만든 갱신본이라면 `--rules <규칙 파일>`도 지정한다.

## 미리보기 조건

- **하루 요약**은 최신 관측일(KST)의 접속 수, 직전 달력일 대비 변화, 위험도 높은 행동과 새 관측 건수를 보여 준다. 마지막 관측일의 수집이 끝나지 않았을 수 있다.
- **위험 전환**은 앞서 확인한 상태가 안정 또는 주의였고 현재 위험일 때 표시한다. 시험 기록이 없다면 직전 관측 가능한 달력일의 상태를 비교에 사용한다. 이전 상태를 확인할 수 없으면 위험 전환으로 추정하지 않는다.
- 시험 기록을 사용하면 동일하거나 더 이전인 갱신본, 같은 날의 중복 요약, 위험이 유지되는 동안의 반복 위험 알림을 막는다. 안정·주의를 관측한 뒤 다시 위험으로 오르면 별도 전환으로 처리한다.

메시지는 건수와 상태만 포함한다. 원본 명령, 전체 IP, 관측된 URL, 인증정보는 포함하지 않는다.
