# 성과를 "탐지율"이 아니라 구체화율·규칙 제거 실험·사람 판정으로 평가한다

현재 규칙 커버리지는 99.2%로 이미 포화다. B19("셸 진입 요청")가 전체 세션의 97.7%에 적중하기 때문이다. 그래서 커버리지로는 개선을 보일 수 없다. 개선 효과는 (1) B19를 뺀 구체화율, (2) 규칙 제거 실험의 재현율·정밀도, (3) 사람 판정 표본의 정밀도로 보고하고, 모든 수치를 세션 단위와 고유 순서 단위로 함께 적는다.

## Considered Options
- 규칙 적중을 정답으로 삼아 Precision/Recall/F1 계산: 순환 논리라서 기각.
- 커버리지만 보고: 이미 포화라서 기각.

## Consequences
- 고유 순서가 133개뿐이고 상위 2개가 세션의 73.4%라서, 세션 가중 수치는 보조로만 쓴다.
- "탐지율"이라는 말은 사람 판정 표본이 있는 범위에서만 쓴다.
