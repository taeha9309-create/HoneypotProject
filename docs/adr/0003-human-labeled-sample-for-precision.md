# 정밀도 주장은 사람이 판정한 표본으로만 하고, 후보를 만든 데이터와 분리해서 평가한다

정답 라벨이 없으므로 정밀도·재현율을 말하려면 사람이 입력을 읽고 행동 범주를 매긴 표본(처음 100개, 필요하면 200개 이상)이 필요하다. 후보를 만들거나 규칙을 고칠 때 본 세션은 평가 표본에서 제외하고, 후보와 평가 방법은 평가 전에 동결한다. 판정은 입력 문자열 관찰이며 실행 성공이나 악성 여부를 판정하지 않는다.

## Considered Options
- 규칙 적중이나 군집을 정답으로 사용: 순환 논리라서 기각.
- 외부 평판 서비스(VirusTotal 등)로 라벨링: 데이터 외부 반출 문제로 승인 없이는 쓰지 않는다.
